# 基准与来源

该 Skill 基于用户认可的 LITTLE SPARK / HAND MADE 十秒短片制作流程。参考海报为本次原创程序绘制的结尾帧，starter 包含同一实现的可配置版本。

最初创意简报由用户提供，对应 Vincentwei1021/mg-styles-15 的 cel animation 提示词：
https://github.com/Vincentwei1021/mg-styles-15/blob/main/prompts/05-cel-boil.md

上游仓库将项目代码、提示词与影片标注为 MIT。当前 starter 没有复制上游影片、画面代码、音轨、图像或字体；角色、字形、纸纹及声音均为本次任务生成。用户提到的 Buck、Giant Ant 等是制作水平和风格参考，不是作品署名或合作关系。

生成新影片时重写 CREDITS.md，列出真正使用的素材及许可证；没有使用的参考素材不应被写成实际来源。Chrome、Playwright、NumPy、FFmpeg 是运行工具，不应把其许可证自动套用到影片上。Skill 不捆绑这些工具的二进制文件。
